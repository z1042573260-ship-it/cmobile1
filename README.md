# 🏗️ 烟台基站工程情报自动化监控系统

## 项目简介

这是一个面向烟台地区的**基站工程情报自动监控系统**，运行在 Windows 电脑上。

**核心业务逻辑**：
> 烟台地区所有新建施工项目（小区、学校、隧道、商场...）建成后都需要基站覆盖。
> 本系统每周自动监控各类政府/招标网站，第一时间发现施工项目，
> 利用豆包 AI 判断哪些项目需要基站，帮助你在竞争对手之前抢占市场。

---

## 功能模块

| 模块 | 功能 |
|------|------|
| 🕷️ **爬虫模块** | 覆盖 27 个数据源，从土地出让到施工招标，全生命周期监控 |
| 🤖 **AI 分析** | 豆包 API 自动判断基站需求、提取结构化字段、优先级打分 |
| 📊 **数据看板** | 多用户 Web 看板，区县分布图、趋势图、项目筛选、Excel导出 |
| 📧 **邮件通知** | 每周自动发送高价值项目汇总邮件 |
| ⏰ **定时任务** | Windows 任务计划程序，每周自动执行 |

## 快速开始

### 1. 安装 Python 环境

确保已安装 Python 3.10 或更高版本：
```bash
python --version
```

### 2. 安装依赖

```bash
cd d:\googledownload\wangluobu_vscode
pip install -r requirements.txt
```

### 3. 配置

编辑 `config/settings.py`，修改以下配置：

```python
# 豆包 API（必填！在火山引擎注册获取）
DOUBAO_API_KEY = "your-actual-api-key"
DOUBAO_MODEL = "your-model-endpoint-id"

# 邮箱配置（用于发送通知邮件）
EMAIL_SENDER = "your-email@qq.com"
EMAIL_PASSWORD = "your-qq-smtp-auth-code"  # QQ邮箱授权码
EMAIL_RECIPIENTS = "user1@qq.com,user2@qq.com"  # 收件人列表
```

### 4. 启动数据看板

双击 `run_webapp.bat` 或在命令行运行：
```bash
python -m webapp.app
```

浏览器访问：**http://localhost:5000**

- 默认管理员：`admin` / `admin123`

### 5. 手动运行爬虫

双击 `run_spider.bat` 或在命令行运行：
```bash
python crawler/scheduler.py
```

## 配置 Windows 定时任务

让系统每周自动执行爬取 + AI 分析 + 邮件通知：

1. 打开 **Windows 任务计划程序**（搜索"任务计划程序"）
2. 点击右侧 **"创建基本任务"**
3. 名称：`烟台基站情报-每周爬取`
4. 触发器：**每周** → 选择周一 → 时间设为凌晨 3:00
5. 操作：**启动程序**
   - 程序：`python`
   - 参数：`crawler/scheduler.py`
   - 起始于：`d:\googledownload\wangluobu_vscode`
6. 完成！

> ⚠️ 电脑需要在设定时间保持开机状态。

## 常见问题

**Q: 豆包 API 在哪里申请？**
A: 访问火山引擎控制台 (console.volcengine.com) → Ark 大模型 → 创建推理接入点

**Q: QQ邮箱 SMTP 授权码怎么获取？**
A: 登录 QQ邮箱 → 设置 → 账户 → POP3/SMTP服务 → 开启 → 获取授权码

**Q: 局域网其他电脑怎么访问看板？**
A: 确保在同一局域网，访问 `http://<本机IP>:5000`（如 `http://192.168.1.100:5000`）

**Q: 爬虫能爬取哪些网站的数据？**
A: 目前框架代码已写好 6 个核心爬虫。每个政府网站的实际 URL 和页面结构需要根据实际情况调整 CSS 选择器。建议先用浏览器开发者工具确认页面结构，再修改对应爬虫文件。
