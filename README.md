# 🏗️ 烟台工程建设信息自动化预警平台

面向**通信基础设施商**的烟台及周边地区建设工程情报系统：自动爬取政府公告 → AI 深度分析 → 坐标定位 → 红黄预警 → 周报推送。

> 每个新建施工项目（小区、学校、产业园、隧道…）建成后都需要基站覆盖。
> 本系统每周自动监控 7 个政府/招标数据源，第一时间发现大型施工项目，
> AI 判断基站需求与跟进时机，帮助在竞争对手之前抢占市场。

---

## ✨ 核心特性

| | 能力 |
|---|---|
| 🕷️ **多源爬虫** | 7 个自动爬虫，覆盖烟台 13 区县政府公告 + 省市招标/规划/招商网站，主力爬虫累计 **466+ 条**公告 |
| 🤖 **AI 情报分析** | 智谱 GLM（免费 `glm-4-flash`）深度推理：项目本质理解 → 基站技术评估（宏站/室分/小站）→ B2B 商机分析，一次调用输出 30+ 字段 |
| 🗺️ **坐标补全** | 高德地理编码 + POI 搜索 + 讯飞星火联网搜索 + 区县虚拟定位兜底，缺坐标记录不入库（保证大屏定位可用） |
| 📡 **3D 预警大屏** | Three.js 烟台 3D 地图：柱状图 / 热力图 / 预警图三模式，下钻到区县街道级（实时高德瓦片），图钉点击查项目 |
| 🗺️ **2D 地图联动** | Leaflet + 高德瓦片（免 key），预警点定位到街道，3D ↔ 2D 状态互恢复 |
| 📊 **数据看板** | 本周/本月/今年统计卡片、区县预警排名、类型/阶段分布、项目明细筛选分页 |
| 📧 **周报推送** | 每周自动生成 Excel（含概览、区县汇总）+ 邮件推送，领导可读 |

## 🏗️ 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│  GitHub Actions（每周一 09:15 定时，全免费）                    │
│                                                             │
│  Layer1 采集        Layer2 汇总     Layer3 分析     Layer4 入库│
│  7个爬虫 ──→ 多源合并 ──→ AI统一情报 ──→ 坐标补全 ──→ TiDB Cloud│
│  (政府官网)          (不去重)       (GLM一次调用)  (高德+讯飞)   │
│                                                             │
│  导出 dashboard_data.json ──→ commit ──→ GitHub Pages 自动部署│
└─────────────────────────────────────────────────────────────┘
               ↓ 5 分钟自动轮询刷新
        浏览器访问 3D 预警大屏 / 数据看板 / 周报
```

- **数据源**：烟台 13 区县政府公告、烟台公共资源交易网、自然资源和规划局、投资促进局、山东省交通运输厅、山东省招标信息、上海建工集团
- **AI 角色**：20 年经验通信基础设施情报分析师（统一温度 0.0，不确定项标注"待核实"）
- **评分引擎**：三层过滤（流程公告过滤 → 标题加权评分 → 详情页内容分析），亿级投资额/万㎡规模信号识别
- **预警规则**：AI 判定红/黄预警才入库，无预警不污染数据库

## 🛠️ 技术栈

Python（requests / bs4 / SQLAlchemy）· 智谱 GLM · 高德开放平台 · 讯飞星火 · TiDB Cloud（MySQL 兼容）· GitHub Actions · GitHub Pages · Three.js · ECharts · Leaflet · Flask

## 🚀 本地运行

```bash
pip install -r requirements.txt
cp .env.example .env        # 填入 TiDB / 智谱 / 讯飞 / 邮箱密钥
python scripts/export_dashboard_db.py     # 导出大屏数据
python crawler/scheduler.py               # 手动跑全管线（爬虫→AI→入库→导出→邮件）
```

前端本地预览：`cd frontend && python -m http.server 8000` → http://localhost:8000

## 📁 目录结构

```
├── crawler/       # 爬虫（spiders/）+ 评分引擎 + 自动化管线 scheduler
├── processor/     # AI 分析管线（智谱 GLM）+ 高德地理编码 + 讯飞搜索 + 坐标补全
├── scripts/       # 汇总去重 / 入库 / 导出（大屏 JSON + Excel 周报）
├── frontend/      # 3D 预警大屏（Three.js）+ 2D 地图 + 数据看板 + 周报页
├── webapp/        # Flask 后端（数据管理 / 审核 / Excel 导出）
├── database/      # SQLAlchemy 模型（TiDB 兼容）
├── config/        # 全局配置（密钥走 .env，不入库）
└── docs/          # 技术汇报 / 部署手册
```
