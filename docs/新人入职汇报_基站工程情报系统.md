# 烟台基站工程情报系统 — 新人入职汇报

> 汇报对象：网络部一把手 ｜ 定位：战略价值汇报（产品经理��角）
> 一句话记忆点：**让网络部每一次基站建设，都变成我们提前布局的机会。**

---

## 一、开场：一句话定位（30 秒）

网络部每天有多少个基站建设商机，在政府的规划、招标、施工公示网站上悄悄出现、又悄悄溜走？

**我的系统，让它们一个都跑不掉。**

烟台基站工程情报系统，把政府网站上每一张工程公示，自动变成一条看得懂、用得上的销售情报——销售打开地图，就知道今天该去哪个区县、找哪家企业、谈什么业务。

---

## 二、战略问题：基站商机的"黄金窗口"正在流失（Why）

基站建设是一套固定的时间线：**规划公示 → 招标 → 施工许可 → 主体竣工**。

对网络部的价值在于——**宏站的最佳抢建窗口，只在"规划 / 招标 / 施工前"**。一旦项目进入竣工交付，施工期抢建窗口关闭，商机基本流失。

| 现状痛点 | 业务影响 |
|---|---|
| 商机靠人工刷政府网站、看行业群 | 滞后、漏抓，等销售知道时窗口已关 |
| 海量公告（规划/招标/施工/招商/新闻）混在一起 | 有效信号被淹没，人工无法逐一甄别 |
| 看不到"具体位置在哪、归哪个区县" | 无法转化为可执行的销售动作 |

**这直接关乎网络部两条核心 KPI：宏站建设进度、政企业务收入。**

---

## 三、解决方案：基站工程情报系统（What）

**产品定位**：一套"采集—研判—呈现"自动化的基站工程情报系统，让政府公示与销售动作之间，不再有信息差。

技术主线（一笔带过，不展开代码）：

```
政府/招标网站 (7大源)  →  AI 研判管线  →  结构化数据库  →  高德地图看板
   爬虫自动采集          分类/预警/商机        MySQL           红黄预警·区县下钻
```

- **采集层**：自动抓取烟台市及各区县自然资源、公共资源交易、投资促进等 7 大官方源
- **研判层**：AI 管线逐条分析——判定项目本质、预警等级（红/黄）、基站需求、商机信号、精确经纬度
- **呈现层**：高德地图看板，红色预警直接落点，支持区县筛选、项目下钻、详情查看

---

## 四、核心能力：三大亮点（How）

### 亮点 1 · 全自动，零人工盯屏
- 7 大官方源自动采集，**每周稳定新增约 20 条**待研判公告
- AI 自动完成分类、预警、商机判断、经纬度补全，不再依赖人工逐条刷网站

### 亮点 2 · 看得懂的地图
- 红色预警直接落在高德地图上，销售打开即知"哪个区县、什么项目、具体位置"
- 支持按区县筛选、按预警等级下钻，指挥调度一目了然

### 亮点 3 · 抢时间，赢在窗口前
- 规划公示当天即完成研判推送，比竞争对手**早数天甚至数周**切入
- 宏站抢建窗口期内精准触达，把"建好再找"变成"建前就谈"

---

## 五、应用成果：数据说话（Value）

| 指标 | 成果 |
|---|---|
| 累计研判公告 | 702 条原始 → **144 条有效红/黄预警** |
| 区县覆盖 | 烟台全域 **14 个区县**全覆盖 |
| 预警结构 | 红色（高优先）89 条 / 黄色 55 条 |
| 更新频率 | 每周稳定增量更新，常态运行 |
| 典型项目 | 工商学院龙口校区（9 栋楼施工总承包）、烟台南站枢纽、威思顿产业园等 |

**视觉主证据**：高德看板红点分布图（覆盖 14 区县的商机热力），是整场汇报冲击最强的一页。

---

## 六、未来规划（Plan）

1. **自动定时分析**：每日/每周自动跑全链，生成商机日报，无需人工触发
2. **多模型兜底**：主模型 + 免费模型自动切换，保障高峰期稳定运行
3. **商机跟进闭环**：预警 → 派单 → 跟进 → 成单，形成可度量的转化链路
4. **可复制推广**：从烟台试点，向全省/全国基站建设情报场景复制

---

## 七、总结（记忆点收尾）

> **让网络部每一次基站建设，都变成我们提前布局的机会。**

这不是一个"爬虫工具"，而是一套把政府公开信息转化为网络部核心业绩的情报系统——它帮网络部，在每一个黄金窗口里，都快人一步。
